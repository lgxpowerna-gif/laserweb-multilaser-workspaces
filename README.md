# Multilaser LaserWeb Workspaces

Optimized LaserWeb (v7) workspace files for Multilaser Creations on Sculpfun S9 lasers (Laser 1 and Laser 2).

These fix common power/raster/cut inconsistencies and apply consistent standards across Christmas ornament (boules de Noël) projects.

## Current Standards (as of 2026-10-27)

### Raster (engraving) — same for all thicknesses
- **Laser 1**: 64%
- **Laser 2**: 59%
- Resolution: 0.18 mm
- Speed: 3000
- Overscan: 2

### Cuts — 3 mm material
- **Laser 1**: 83% power @ 175 mm/min (trous ×2 passes, contour + rectangle ×1)
- **Laser 2**: 85% power @ 100 mm/min (trous ×2, contour + rectangle ×1)

### Cuts — 6 mm material
- Unchanged from previous (project-specific; see individual workspaces)

## How to use
1. Download the appropriate zip for your laser and project.
2. Extract it.
3. In LaserWeb, load the workspace / project files.
4. Verify machine profile (Sculpfun S9 / GRBL, PWM max 1000).
5. Run.
